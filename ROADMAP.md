# Roadmap für Sonar
Diese Roadmap ist eine kurze Zusammenfassung der gepanten Features

## Account-System
Das Account-System wird erweitert, sodass Nutzer:innen ein vollwertiges Profil haben, welches sie anpassen können.
Zudem wird ein Algorithmus implementiert, der die Übersicht der aktuellen Events an das jeweilige Interessenprofil anpasst

## Sonar Credits
Mit Sonar Credits können Nutzer:innen an Events teilnehmen, die kostenpflichtig wären. Die Credits können von der Stadt aufgeladen werden.
Dadurch wird es auch Kindern aus finanziell schwächeren Familien ermöglicht, am sozialen Leben teilzunehmen.

## Chat Funktion (für Kinder)
Die Chat Funktion ist wichtig, um die Kinder untereinander zu vernetzen und ihnen so zu ermöglichen, gemeinsam Events zu teilen und an diesen teilzunehmen.
Zusätzlich ist die Chat Funktion ein weiteres Argument, Sonar regelmäßig zu nutzen und so auch auf neue Events aufmerksam zu werden.
Die Kommunikation wird hier erst möglich, wenn sich Kinder persönlich getroffen haben und einen QR-Code zur Verknüfpung gescanned haben.
Dieser Sicherheitsmechanismus schützt vor Mobbing, lässt unbekannte Dritte draußen und schützt so die Kinder vor potentiellen Gefahren in sozialen Netzwerken.

## Chat Funktion (für alle)
Die Chat Funktion für alle erweitert die für Kinder. 
Hier ist der Fokus auf den Eltern und den Lehrer:innen.
Die Kommunikation wird hier auch erst möglich, wenn sich beide Parteien persönlich getroffen haben und einen QR-Code zur Verknüfpung gescanned haben.
